# Poster layout specification

## Canvas

- Size: A1 portrait (594 x 841 mm / 23.39 x 33.11 inches).
- Grid: a full-width header, followed by two content columns and a full-width evidence band.
- Palette: deep navy (`#153A5B`), clinical teal (`#008C95`), light cyan (`#EAF7F8`), warm gold (`#F4BE4F`), white.
- Type: Arial / Helvetica-like sans serif; dark navy headings; readable high-contrast body copy.

## Reading order

1. Header: title, affiliations, quantitative headline.
2. Upper left: motivation, patient-level workflow, and experimental setup.
3. Upper right: PoE architecture as the hero visual and concise model explanation.
4. Middle evidence band: HGB ablation as the visual hero, five-seed main comparison, and missingness simulation.
5. Footer: clinical role, limitations, contact/QR placeholder.

## Visual assets

- Hero workflow: manuscript Figure 1.
- Hero architecture: manuscript Figure 2.
- Simplified five-seed comparison table: F1, ROC-AUC, and NPV for Concat Fusion and MM-VAE.
- HGB ablation: manuscript Figure 4.
- Gradual missingness: manuscript Figure 6.

Use the versions extracted from the supplied manuscript; do not redraw or alter the reported values.

## Hierarchy notes

- The PoE fusion image should be the largest method graphic.
- HGB ablation should be visually strongest result: make the stable MM-VAE result legible from 1-2 metres.
- Use result callouts only for values present in the manuscript/project metrics.
- Label five-seed means separately from representative-run ablation and missing-modality results.
- Keep the clinical limitation visible so the poster does not imply diagnostic replacement.
